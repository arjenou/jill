# 江西星科电子基材有限公司 React 官网

基于 React、TypeScript、Vite、React Router 与 Tailwind CSS 构建的多页面路由企业官网。

## 页面路由

- `/` 首页
- `/about` 关于我们
- `/business` 业务范围
- `/products` 产品中心
- `/capabilities` 制造能力
- `/honors` 荣誉资质
- `/contact` 联系我们

## 本地运行

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist` 目录。

## 内容范围

网站仅使用企业公开资料，包括公司介绍、产品型号、制造设备、产业协同、资质荣誉与联系方式。交易方案、估值、融资余额、预测利润及未公开采购计划没有进入网站内容。
